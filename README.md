# TapMusic

TapMusicは、Unityで制作した4レーン形式のリズムゲームです。  
PC版・Android版でのプレイに対応しています。

現在はテスト版として公開しており、タップノーツのみ対応しています。  
一部譜面は制作途中です。

## Download

最新版はGitHub Releasesからダウンロードできます。  
zipファイルをダウンロードし、解凍して実行してください。

## Songs / Charts

現在プレイ可能な譜面は以下の通りです。

- あふぇめーしょん
  - Hard
- サクラリズム
  - Easy / Normal / Hard
- Calamity Fortune
  - Hard（製作途中）

## Controls

### Android

- タップ操作

### PC

- 選択画面：マウス操作
- プレイ画面：左レーンから順に `D` `F` `J` `K`

## Features

- 4レーンのリズムゲーム
- タップノーツに対応
- 曲名順・難易度順のソート
- 昇順・降順の切り替え
- NotesSpeed設定
- MusicOffset設定
- PlayFabを利用したオンライン機能

## Settings

### NotesSpeed

ノーツの流れる速度を調整できます。

### MusicOffset

曲が流れ始めるタイミングを調整できます。

## Online Features

PlayFabを利用したオンライン機能を実装しています。

## Status

このゲームは現在テスト版です。  
今後の更新で、譜面や機能の追加・調整を行う予定です。
